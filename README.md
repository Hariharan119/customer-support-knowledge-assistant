# Customer Support Knowledge Assistant

## Problem
Customer support agents find it difficult to locate accurate answers across many product manuals and FAQ documents.

## Proposed solution
A document-grounded AI assistant for customer support questions.

## Planned stack
- Frontend: Streamlit
- Backend: FastAPI
- LLM: Approved OpenAI API access
- Retrieval: Embeddings + FAISS (subject to validation)
